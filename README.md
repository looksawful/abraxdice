# abraxdice

Целевой адрес магазина: https://abraxdice.ru/ (домен ещё не подключён). Демонстрационный прототип: https://looksawful.github.io/abraxdice/

Это не действующий магазин: наличие, характеристики и сроки не подтверждены; оплата и отправка заказов не работают.

## Целевая модель продукта (24.11.2026)

Основной товар — набор кубиков. Покупатель выбирает готовый набор из каталога или параметры своего набора, добавляет набор в корзину, затем указывает контакты и способ доставки, оформляет заказ и оплачивает его через Robokassa в пользу продавца (Юры). Платёжная интеграция отложена. Термины: [CONTEXT.md](CONTEXT.md).

Текущее ограничение: прототип пока моделирует одиночные кубики и ведёт из корзины в общую форму связи. Переход к наборам требует согласованных состава, параметров и цены; старые позиции корзины нельзя автоматически считать наборами. Отдельный checkout и подтверждение заказа должны предшествовать подключению оплаты.

## Структура и публикация

- Маршруты: `/`, `/catalog/`, `/configure/`, `/cart/`, `/contacts/`, `/production/`, `/product/`, `/terms/`, `/cookies/`, `/consent/`. Тёмная тема основная и включена по умолчанию; ручной переключатель и сохранение выбора работают. Отдельных `/dark/` страниц нет.
- `main` — исходный код; GitHub Actions собирает статический экспорт и напрямую публикует его через Pages deployment. Историческая `gh-pages` вручную не редактируется.
- Эксперименты — в отдельной ветке по запросу; в `main` только согласованные изменения.

Решения, замечания и результаты проверок: [единый Issue #5](https://github.com/looksawful/abraxdice-internal/issues/5) и связанная задача Asana. Исследовательские журналы в репозитории не ведём.
