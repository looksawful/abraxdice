# Правила работы с abraxdice

- Единственное актуальное название бренда и магазина — abraxdice; целевой адрес https://abraxdice.ru/. Не использовать прежнее имя в новом интерфейсе, документации или задачах; только совместимость старых данных и исторические ссылки.

- Перед изменениями прочитай [README.md](README.md) и затронутые файлы. Текущее поведение определяют исходники и тесты.
- `main` — единственная рабочая ветка; CI публикует Pages напрямую через workflow. `gh-pages` — историческая ветка, её не редактировать. Отдельную ветку создавай только по просьбе пользователя.
- Сохраняй утверждённые тексты и заглушки: Hero «Заголовок», существующий текст, кнопка «Создать случайный кубик». Меняй их только по явному запросу.
- Hero: пассивная 3D-модель с непрерывным вращением, без управления и фокуса. Остальные 3D-превью вращаются автоматически до первого взаимодействия; затем пользователь вращает перетаскиванием и немного масштабирует колёсиком, без видимых контролов (кроме метки 3D-превью вне Hero). Сохраняй `prefers-reduced-motion`. Одно дерево маршрутов.
- Тёмная тема утверждена 24.11.2026 и используется по умолчанию. Существующий ручной переключатель и сохранение выбора сохраняются до отдельного решения. Не добавляй неподтверждённые сведения о товаре, наличии, материалах, сроках или контактах. Адрес самовывоза остаётся шаблоном с многоточиями, как указал пользователь.
- Предметная модель: [CONTEXT.md](CONTEXT.md), целевой путь покупки в [README.md](README.md). Основная единица продажи — набор, не отдельный кубик. Новая логика каталога, конструктора, цен, корзины и checkout должна исходить из этого правила. Не преобразовывай старые позиции одиночных кубиков в наборы без согласованной миграции. Тексты старого прототипа не считать целевой моделью.
- Прототип не принимает оплату и не отправляет заявки; не представляй его как работающий магазин. Robokassa подключается позднее, после реализации оформления заказа. Не имитировать успешную оплату.
- После изменения кода выполни `npm test`, `npm run typecheck`, `npm run build` и проверь затронутые страницы в браузере. Непроверенное отмечай явно.
- История решений, QA и передача работ: [Issue #5](https://github.com/looksawful/abraxdice-internal/issues/5) и связанная задача Asana. Дополняй существующие записи, не создавай журналы исследований в README/AGENTS/docs.
